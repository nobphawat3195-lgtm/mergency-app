# 3. รายละเอียดหน้าจอ — Emergency Flow

อ้างอิงโดยตรงจากภาพหน้าจอ 24CarFix ที่ให้มา ปรับโครงสร้างให้ reusable

## Screen 1: หมวดบริการ (Step 1/4)

- Stepper แนวนอนด้านบน: วงกลม 4 จุด เชื่อมเส้น (1 บริการ, 2 บริการย่อย, 3 ประเภทรถ, 4 ประเภทย่อย)
- สถานะ: ✓ (เสร็จ, สีส้ม), current (สีส้ม เลขวงกลม), pending (สีเทา)
- List การ์ดหมวดบริการ: ไอคอน + ชื่อ + คำอธิบายสั้น
  - ไดนาโม/ระบบไฟ, แบตเตอรี่, ยาง, กุญแจ, เครื่องยนต์, ลากรถ

## Screen 2: บริการย่อย (Step 2/4)

- Header แสดงหมวดที่เลือก (ไอคอน + ชื่อ + "เลือกบริการที่ต้องการ")
- List card บริการย่อย แต่ละใบมี:
  - ชื่อบริการ (เช่น "เรียกช่างให้ไปดูก่อน จ่ายเงินหน้างาน")
  - คำอธิบาย 1 บรรทัด
  - ราคาบาท ชิดขวา (สีส้ม ตัวหนา)
  - ปุ่ม (ⓘ) info — เปิด bottom sheet อธิบายเงื่อนไข/ขอบเขตบริการ (สำคัญมาก ลดข้อพิพาทเรื่องราคา)
- **หลักการราคา**: แยก "ค่าเรียก/ประเมินหน้างาน" (ราคาต่ำ ~400-749฿) ออกจาก "ราคาเริ่มต้นบริการเต็ม" (~850-1,200฿) เสมอ ไม่รวมค่าอะไหล่

## Screen 3: ประเภทรถ (Step 3/4)

- Grid หรือ list: เก๋ง, SUV, กระบะ, รถตู้, มอเตอร์ไซค์, EV
- แต่ละประเภทอาจมีราคาต่างกัน (เช่น กระบะ/SUV ค่าแรงสูงกว่าเก๋ง)

## Screen 4: ประเภทย่อย + สรุปราคา (Step 4/4)

- เลือกรายละเอียดเพิ่มเติม (ยี่ห้อ/ขนาดเครื่อง ถ้าจำเป็นต่อราคา)
- การ์ดสรุปราคาสุดท้าย + ปุ่ม "ยืนยันเรียกช่าง" ขนาดใหญ่ sticky ด้านล่าง

## Screen 5: จับคู่ช่าง (Matching)

- แผนที่เต็มจอ, pin ตำแหน่งลูกค้า + หมุดช่างที่ว่างใกล้เคียง (คล้าย Grab กำลังหาคนขับ)
- Animation "กำลังค้นหาช่างใกล้คุณ..." + timeout fallback (ถ้าเกิน 60-90 วิ ไม่มีช่างรับ ให้ขยายรัศมีค้นหาอัตโนมัติ)

## Screen 6: ติดตามงาน (Tracking)

- แผนที่ real-time: หมุดช่าง + เส้นทาง + ETA
- การ์ดข้อมูลช่าง (รูป, ชื่อ, เรตติ้ง, ทะเบียนรถ/อุปกรณ์) + ปุ่มโทร/แชท
- Timeline สถานะ: รับงาน → กำลังเดินทาง → ถึงจุดหมาย → กำลังซ่อม → เสร็จสิ้น

## Screen 7: ปิดงาน + ชำระเงิน

- สรุปค่าใช้จ่ายจริง (แยกค่าเรียก/ค่าแรง/ค่าอะไหล่ถ้ามี — ต้องขึ้นราคาเพิ่มเติมให้ลูกค้ากดยืนยันก่อนซ่อมเกินราคาประเมินเสมอ)
- ช่องทางชำระเงิน: บัตร/พร้อมเพย์/wallet ในแอป
- ให้คะแนนช่าง + คอมเมนต์

## Home Screen (รายละเอียดเพิ่มจากภาพ)

- Location picker header แบบ pin icon + dropdown
- Hero card 2 คอลัมน์ ("เรียกช่างฉุกเฉิน" badge แนะนำ, "รถสไลด์/รถยก")
- Secondary cards: บริการมอเตอร์ไซค์, สั่งอะไหล่ใกล้ฉัน, ผู้ช่วย AI แชท
- Banner carousel auto-slide พร้อม dot indicator
- Grid หมวดหมู่บริการ 4 คอลัมน์ ไอคอนสไตล์ 3D-flat สีสันสดใส (แนะนำใช้ Lottie/SVG illustration แทนรูปถ่ายจริง ให้ความรู้สึก friendly ไม่น่ากลัวตอนรถเสีย)
