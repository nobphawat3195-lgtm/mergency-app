# 4. รายละเอียดหน้าจอ — Pre-purchase Inspection Flow (ฟีเจอร์ใหม่)

ฟีเจอร์นี้ไม่มีต้นแบบจาก 24CarFix ต้องออกแบบใหม่ทั้งหมด โฟกัสที่ "ความน่าเชื่อถือ" มากกว่า "ความเร็ว"

## Screen 1: หน้าเริ่มต้นบริการตรวจรถ

- Hero image/illustration อธิบายบริการสั้นๆ: "ตรวจรถมือสองก่อนโอนเงิน โดยผู้เชี่ยวชาญมืออาชีพ"
- Trust signals: จำนวนผู้เชี่ยวชาญที่ผ่านการรับรอง, จำนวนคันที่ตรวจไปแล้ว, ตัวอย่างรายงาน (sample report)
- ปุ่ม "เริ่มจองตรวจรถ"

## Screen 2: กรอกข้อมูลรถ + สถานที่นัด

Form fields:
- ยี่ห้อ / รุ่น / ปีที่จดทะเบียน / เลขไมล์โดยประมาณ
- ประเภทผู้ขาย: โชว์รูม / เต็นท์รถ / บุคคลทั่วไป / ลานประมูล
- สถานที่นัดตรวจ (pin แผนที่ + ที่อยู่)
- เบอร์ติดต่อผู้ขาย (optional — เผื่อผู้เชี่ยวชาญต้องประสานงานหน้างาน)

## Screen 3: เลือกแพ็กเกจตรวจ

Card เปรียบเทียบ 2 แพ็กเกจ (แบบตารางเทียบ feature):

| รายการตรวจ | Basic (~1,500-2,000฿) | Full (~3,000-4,500฿) |
|---|---|---|
| เครื่องยนต์ | ✅ | ✅ |
| ช่วงล่าง/เบรก | ✅ | ✅ |
| ระบบไฟฟ้าเบื้องต้น | ✅ | ✅ |
| สแกน OBD หาโค้ดผิดปกติ | ❌ | ✅ |
| ตรวจโครงสร้างตัวถัง (ชนหนัก/น้ำท่วม) | ❌ | ✅ |
| เช็คประวัติทะเบียน/ไฟแนนซ์ค้าง | ❌ | ✅ |
| รายงาน | สรุปสั้น | เต็มรูปแบบ + วิดีโอ 360° |

## Screen 4: เลือกวันเวลานัด + ผู้เชี่ยวชาญ

- ปฏิทินเลือกวัน + time slot ที่ว่าง
- List ผู้เชี่ยวชาญที่ว่างในพื้นที่ พร้อม badge "ผู้เชี่ยวชาญตรวจสภาพ" (แยกจาก badge ช่างซ่อมทั่วไป), เรตติ้ง, จำนวนงานที่เคยตรวจ
- (ทางเลือก) ให้ระบบสุ่มจับคู่อัตโนมัติได้เช่นกัน สำหรับ user ที่ไม่อยากเลือกเอง

## Screen 5: ยืนยัน + ชำระเงินมัดจำ

- สรุปข้อมูลทั้งหมด + ราคาสุทธิ
- ชำระมัดจำ (กันการนัดแล้วไม่มา) ส่วนที่เหลือชำระหลังตรวจเสร็จหรือชำระเต็มจำนวนล่วงหน้าก็ได้ (แล้วแต่ business model)

## Screen 6: สถานะรอผู้เชี่ยวชาญ (ระหว่างรอวันนัด)

- Timeline: จองสำเร็จ → ผู้เชี่ยวชาญยืนยันรับงาน → ใกล้ถึงวันนัด (แจ้งเตือน 1 วันล่วงหน้า) → วันนัดถึง

## Screen 7: ระหว่างตรวจ (ฝั่ง Provider App)

*หน้านี้อยู่ใน Provider App แต่มีผลต่อสิ่งที่ลูกค้าเห็น*
- Digital checklist แบ่งหมวด: เครื่องยนต์ / ช่วงล่าง / ระบบไฟฟ้า / ตัวถัง / ภายใน / เอกสาร
- แต่ละหมวด: ให้คะแนนสภาพ (ดี/พอใช้/ควรระวัง/มีปัญหา) + ถ่ายรูป/วิดีโอแนบทุกจุดที่พบปัญหา + เขียนหมายเหตุ
- ปุ่ม "ส่งรายงาน" เมื่อตรวจครบทุกหมวด — ระบบ generate รายงานอัตโนมัติ

## Screen 8: รายงานผลตรวจ (ลูกค้าเห็นหน้านี้)

- **Scorecard สรุป**: วงกลม/แถบคะแนนรวม + คะแนนแยกรายระบบ (เครื่องยนต์ 8/10, ช่วงล่าง 6/10 ฯลฯ) ใช้สีไล่ระดับเขียว-เหลือง-แดงให้เข้าใจง่ายทันทีแม้ไม่มีความรู้เรื่องรถ
- รายละเอียดแต่ละหมวด: expand ดูรูป/วิดีโอ/หมายเหตุของผู้เชี่ยวชาญ
- คำแนะนำสรุปท้ายรายงาน (เช่น "ควรต่อรองราคาเพิ่มเนื่องจากพบรอยชนบริเวณ...")
- ปุ่ม "ดาวน์โหลด PDF" / "แชร์รายงาน"
- ปุ่มให้คะแนนผู้เชี่ยวชาญ

## หมายเหตุการออกแบบสำคัญ

- โทนสีของ flow นี้ควรต่างจาก Emergency เล็กน้อย (เช่น ใช้สีน้ำเงิน/เขียวแทนสีส้มเร่งด่วน) เพื่อสื่อว่าเป็นบริการที่ "ผ่อนคลาย วางแผนได้" ไม่ใช่ฉุกเฉิน
- Scorecard คือหัวใจของ UX นี้ — ควรลงทุนออกแบบให้ดีที่สุด เพราะเป็น deliverable ที่ลูกค้าจ่ายเงินซื้อจริงๆ
