## FixGo (แอปลูกค้า)

**ชื่อแอป** (ไม่เกิน 30 ตัวอักษร)
```
FixGo เรียกช่างซ่อมรถ 24 ชม.
```

**คำอธิบายย่อ** (Google Play ไม่เกิน 80 ตัวอักษร / App Store Subtitle ไม่เกิน 30 ตัวอักษร)
```
รถเสียเรียกช่างใกล้คุณ จั๊มแบต ปะยาง รถสไลด์ รู้ราคาก่อนซ่อม
```
```
ช่างซ่อมรถถึงที่ 24 ชั่วโมง
```

**คำอธิบายเต็ม**
```
รถสตาร์ทไม่ติด ยางแบน กุญแจหาย น้ำมันหมด หรือรถดับกลางทาง เรียกช่างใกล้คุณได้ใน FixGo

ใช้ง่าย แม้ไม่รู้ว่ารถเป็นอะไร
• กดอาการรถ เช่น "แบตหมด สตาร์ทไม่ติด" ระบบเลือกบริการให้เอง
• เลือกประเภทรถ ยืนยันจุดนัด แล้วระบบส่งงานหาช่างที่ใกล้ที่สุด

รู้ราคาก่อนเริ่มงานทุกครั้ง
• ราคาเริ่มต้นแสดงก่อนเรียก เช่น จั๊มแบต 600 บาท ปะยาง 790 บาท
• ช่างส่งราคาจริงหลังดูหน้างาน คุณกดยืนยันก่อน ช่างจึงเริ่มงานได้

รู้ว่าใครกำลังมา
• แผนที่และเวลาที่ช่างจะถึง
• การ์ดช่าง: รูป คะแนน จำนวนงาน ประสบการณ์ รถ และทะเบียนรถ
• ช่างทุกคนผ่านการตรวจเอกสารและรูปเครื่องมือจากทีมงานก่อนรับงาน

ปลอดภัยสำหรับคนที่คุณห่วง
• แชร์ลิงก์ให้ครอบครัวติดตามได้โดยไม่ต้องติดตั้งแอป
• ปุ่มโทรเบอร์ฉุกเฉินในหน้าติดตามงาน

จ่ายง่าย
• จ่ายเงินสดกับช่าง หรือสแกนพร้อมเพย์แล้วแนบสลิป

บริการ
จั๊มแบต เปลี่ยนแบต ปะยาง เปลี่ยนยางอะไหล่ ช่างกุญแจ ส่งน้ำมัน เช็คไฟเตือนหน้าปัด รถดับกลางทาง ช่างรถ EV รถสไลด์ (1,500–5,000 บาทตามระยะทาง) และตรวจรถมือสองก่อนซื้อ 134 จุด (1,990 บาท)

เข้าสู่ระบบด้วย LINE หรือเบอร์โทร ลบบัญชีได้เองในแอป
```

**หมวดหมู่:** Google Play: ยานยนต์ (Auto & Vehicles) / App Store: Utilities (หมวดรอง: Travel)

**คำค้น App Store** (ไม่เกิน 100 ตัวอักษร คั่นด้วยจุลภาค ไม่ต้องใส่ชื่อแอปซ้ำ)
```
ช่างซ่อมรถ,จั๊มแบต,ปะยาง,รถสไลด์,รถยก,ช่างกุญแจ,แบตหมด,รถเสีย,ตรวจรถมือสอง,ช่างนอกสถานที่
```

## FixGo Fixer (แอปช่าง)

**ชื่อแอป**
```
FixGo Fixer รับงานช่างซ่อมรถ
```

**คำอธิบายย่อ**
```
รับงานซ่อมรถใกล้คุณ สมัครด้วย LINE รายได้เข้ากระเป๋าเมื่อยืนยันการชำระ
```
```
แอปรับงานสำหรับช่าง FixGo
```

**คำอธิบายเต็ม**
```
FixGo Fixer คือแอปสำหรับช่างที่อยากรับงานช่วยเหลือรถใกล้ตัว ทั้งจั๊มแบต ปะยาง ช่างกุญแจ ส่งน้ำมัน รถสไลด์ และตรวจรถมือสอง

สมัครง่าย
• สมัครด้วย LINE หรือเบอร์โทร
• กรอกข้อมูล รูปหน้าตรง รูปเครื่องมือ ทะเบียนรถ และบริการที่รับ
• ทีมงานตรวจแล้วแจ้งผลในแอป ถ้าข้อมูลไม่ครบจะบอกเหตุผลและส่งใหม่ได้

รับงานใกล้ตัว
• เปิด "พร้อมรับงาน" ระบบส่งงานที่ใกล้คุณที่สุด
• เห็นบริการ ระยะทาง จุดนัด และราคาประเมินก่อนกดรับ
• ส่งราคาจริงหลังดูหน้างาน ลูกค้ายืนยันแล้วจึงเริ่มงาน

รายได้ชัดเจน
• หน้าหลักสรุปงานเสร็จและรายได้วันนี้
• งานพร้อมเพย์: ส่วนของคุณเข้ากระเป๋าเมื่อระบบยืนยันยอด แล้วกดขอเบิกได้
• งานเงินสด: เห็นค่าบริการแพลตฟอร์มที่ต้องโอนคืน และโอนผ่าน QR ในแอปได้

งานตรวจรถมือสอง
• แบบฟอร์มตรวจ 134 จุด พร้อมตัวอย่างมุมถ่ายรูป ส่งรายงานให้ลูกค้าในแอป
```

**หมวดหมู่:** Google Play: ธุรกิจ (Business) / App Store: Business

**คำค้น App Store**
```
งานช่าง,รับงานซ่อมรถ,ช่างซ่อมรถ,หางานช่าง,จั๊มแบต,ปะยาง,รถสไลด์,ช่างกุญแจ,งานอิสระ
```

### Google Play: Data safety

ตอบให้ตรงกับตาราง App Privacy ใน `docs/APP_REVIEW.md` ข้อ 4
- **เก็บข้อมูล:** ใช่ ใช้เพื่อการทำงานของแอปทั้งหมด ไม่ใช้โฆษณาหรือติดตามข้ามแอป
- **ส่งข้อมูลแบบเข้ารหัสระหว่างทาง:** ใช่ (HTTPS)
- **ผู้ใช้ขอลบข้อมูลได้:** ใช่ ทั้งในแอปและผ่านลิงก์ขอลบบัญชี
- **แชร์ข้อมูลกับบุคคลที่สาม:** ไม่แชร์ ผู้ให้บริการที่ทำงานแทนเรา (เซิร์ฟเวอร์ ส่ง SMS แจ้งเตือน) ไม่นับเป็นการแชร์ตามนิยามของ Google
- **ข้อมูลที่ลูกค้าและช่างเห็นของกันและกัน:** ลูกค้าเห็นชื่อ เบอร์โทร รูป รถและทะเบียนรถ คะแนน และตำแหน่งของช่างเฉพาะช่วงที่ช่างกำลังเดินทางมา ช่างเห็นจุดนัด หมายเหตุ รูปอาการรถ และข้อมูลรถที่ต้องใช้ทำงาน ทั้งหมดนี้ระบุในนโยบายความเป็นส่วนตัวแล้ว
