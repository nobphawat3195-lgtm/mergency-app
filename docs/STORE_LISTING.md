## ภาพหน้าจอ

อยู่ใน `docs/store/` ถ่ายจากแอปเวอร์ชันปัจจุบันที่ build เป็นเว็บ ต่อ backend จริงในเครื่องด้วยข้อมูลสมมติ
- ชื่อช่าง ทะเบียน ที่อยู่ ราคา คะแนน และรายได้เป็นข้อมูลสมมติ แต่ทุกตัวเลขมาจาก API จริงตามที่ระบบคำนวณ
- รูปรถ รูปยาง และใบเสร็จในภาพเป็นภาพตัวอย่างที่วาดขึ้น ไม่ใช่รูปของลูกค้าจริง
- เครื่องที่ถ่ายออกเน็ตไป OpenStreetMap ไม่ได้ ภาพแผนที่ในหน้าติดตามงานจึงเป็นแผนที่จำลอง และที่อยู่บนหัวหน้าแรกเป็นที่อยู่ตัวอย่าง (ในแอปจริงใช้แผนที่และที่อยู่จาก OpenStreetMap)
- บริการที่ยังไม่เปิด (รถสไลด์/รถยก ช่างกุญแจ ช่างรถ EV ตรวจรถมือสอง) ปิดไว้ในระบบก่อนถ่าย จึงไม่มีในภาพ

## FixGo (แอปลูกค้า)

ข้อความทั้งหมดใช้แนวเดียวกับหน้าแรกของแอป ห้ามอ้าง "24 ชม." ห้ามพูดถึงการรับประกันงาน
และห้ามอ้างบริการที่ยังไม่เปิด (รถสไลด์/รถยก ช่างกุญแจ ช่างรถ EV ตรวจรถมือสอง) ถ้าเปิดบริการเหล่านี้ในหน้าแอดมินภายหลัง ค่อยเพิ่มกลับเข้าคำอธิบาย

**ชื่อแอป** (ไม่เกิน 30 ตัวอักษร: 27)
```
FixGo เรียกช่างซ่อมรถถึงที่
```

**คำอธิบายย่อ** (Google Play ไม่เกิน 80 ตัวอักษร: 65)
```
รถเสียกลางทาง ไม่ต้องอยู่คนเดียว เรียกช่างใกล้คุณ รู้ราคาก่อนซ่อม
```
**App Store Subtitle** (ไม่เกิน 30 ตัวอักษร: 25)
```
รถเสีย ไม่ต้องอยู่คนเดียว
```

**คำอธิบายเต็ม**
```
รถเสียกลางทาง ไม่ต้องอยู่คนเดียว
แบตหมด ยางแบน น้ำมันหมด ไฟเตือนขึ้น หรือรถดับกลางทาง เรียกช่างใกล้คุณมาดูถึงที่ด้วย FixGo

ใช้ง่าย แม้ไม่รู้ว่ารถเป็นอะไร
• กดอาการรถ เช่น "แบตหมด สตาร์ทไม่ติด" ระบบเลือกบริการให้เอง
• เลือกประเภทรถ ยืนยันจุดนัด แล้วระบบส่งงานหาช่างที่อยู่ใกล้

ช่างตัวจริงที่ยืนยันตัวตนแล้ว
• ช่างทุกคนผ่านการตรวจข้อมูล รูปหน้าตรง และรูปเครื่องมือจากทีมงานก่อนรับงาน
• เห็นหน้า ชื่อ คะแนน รถ และทะเบียนรถของช่างก่อนเจอตัว

รู้ราคาก่อนซ่อม
• เห็นราคาเริ่มต้นก่อนเรียก เช่น จั๊มแบต 600 บาท ปะยางตัวหนอน 790 บาท
• ช่างเสนอราคาจริงหลังดูหน้างาน คุณกดยืนยันก่อน ช่างจึงเริ่มงานได้

รู้ว่าช่างอยู่ไหน คุยกับช่างได้ตลอด
• เห็นตำแหน่งช่างบนแผนที่และเวลาที่ช่างจะถึง
• แชทหรือโทรหาช่างในแอป ส่งรูปจุดจอดหรืออาการรถให้ช่างดูก่อนได้
• แชร์ลิงก์ให้คนที่คุณรักติดตามได้โดยไม่ต้องติดตั้งแอป และมีปุ่ม SOS โทรเบอร์ฉุกเฉิน

จบงานแบบมีหลักฐาน
• ช่างแนบรูปรถหลังซ่อมเสร็จ และรูปใบเสร็จ (ถ้ามี) ตอนปิดงาน
• จ่ายเงินสดกับช่าง หรือชำระผ่านพร้อมเพย์ในแอป
• ให้คะแนนช่าง และบอกเราได้ว่าอยากให้ปรับปรุงอะไร

บริการที่เปิดอยู่ตอนนี้
จั๊มแบต เปลี่ยนแบตเตอรี่ ปะยาง เปลี่ยนยางอะไหล่ ส่งน้ำมันฉุกเฉิน เช็คไฟเตือนหน้าปัด รถสตาร์ทไม่ติด รถดับกลางทาง และงานระบบไฟ ไดชาร์จ ไดสตาร์ท นอกสถานที่

เข้าสู่ระบบด้วย LINE หรือเบอร์โทร ลบบัญชีได้เองในแอป
```

**หมวดหมู่:** Google Play: ยานยนต์ (Auto & Vehicles) / App Store: Utilities (หมวดรอง: Travel)

**คำค้น App Store** (ไม่เกิน 100 ตัวอักษร คั่นด้วยจุลภาค ไม่ต้องใส่ชื่อแอปซ้ำ: 95)
```
ช่างซ่อมรถ,จั๊มแบต,ปะยาง,แบตหมด,ยางแบน,รถเสีย,สตาร์ทไม่ติด,ส่งน้ำมัน,ช่างนอกสถานที่,ช่วยเหลือรถ
```

สมัครง่าย
• สมัครด้วย LINE หรือเบอร์โทร

รับงานใกล้ตัว ในเวลาที่คุณสะดวก

• เห็นบริการ ระยะทาง จุดนัด และราคาประเมินก่อนกดรับ

• ปิดงานด้วยรูปรถหลังซ่อมเสร็จ และแนบรูปใบเสร็จได้

• งานเงินสด: เห็นค่าบริการแพลตฟอร์มที่ต้องโอนคืนทุกรายการ และโอนผ่าน QR ในแอปได้

### Google Play: Data safety

ตอบให้ตรงกับตาราง App Privacy ใน `docs/APP_REVIEW.md` ข้อ 4
- **เก็บข้อมูล:** ใช่ ใช้เพื่อการทำงานของแอปทั้งหมด ไม่ใช้โฆษณาหรือติดตามข้ามแอป
- **ส่งข้อมูลแบบเข้ารหัสระหว่างทาง:** ใช่ (HTTPS)
- **ผู้ใช้ขอลบข้อมูลได้:** ใช่ ทั้งในแอปและผ่านลิงก์ขอลบบัญชี
- **แชร์ข้อมูลกับบุคคลที่สาม:** ไม่แชร์ ผู้ให้บริการที่ทำงานแทนเรา (เซิร์ฟเวอร์ ส่ง SMS แจ้งเตือน) ไม่นับเป็นการแชร์ตามนิยามของ Google
- **ข้อมูลที่ลูกค้าและช่างเห็นของกันและกัน:** ลูกค้าเห็นชื่อ เบอร์โทร รูป รถและทะเบียนรถ คะแนน และตำแหน่งของช่างเฉพาะช่วงที่ช่างกำลังเดินทางมา ช่างเห็นจุดนัด หมายเหตุ รูปอาการรถ และข้อมูลรถที่ต้องใช้ทำงาน ทั้งสองฝั่งเห็นข้อความและรูปที่ส่งในแชทของงานนั้น และลูกค้าเห็นรูปรถ/ใบเสร็จที่ช่างแนบตอนปิดงาน ทั้งหมดนี้ระบุในนโยบายความเป็นส่วนตัวแล้ว
- **ประเภทข้อมูลใน Data safety:** ข้อความในแอป (Messages: แชทกับช่าง/ลูกค้า) และรูปภาพ (Photos: รูปอาการรถ รูปในแชท รูปปิดงาน สลิป) ติ๊กเป็นข้อมูลที่เก็บ ใช้เพื่อการทำงานของแอป ไม่บังคับ (ผู้ใช้เลือกส่งเอง)
