# เช็กลิสต์เปิดตัว FixGo

ทำตามลำดับจากบนลงล่าง ข้อที่ขึ้นต้นด้วย ✅ ทำเสร็จแล้วในโค้ด ข้อที่มีกล่อง `[ ]` เจ้าของต้องทำเอง
เพราะต้องใช้บัญชี บัตร หรือข้อมูลของเจ้าของ

- ✅ แอปลูกค้า แอปช่าง หน้าแอดมิน และระบบหลังบ้านครบทุก flow: เรียกช่าง, ติดตามงาน, เสนอราคา, จ่ายเงิน, ให้คะแนน, ตรวจรถมือสอง
- ✅ ช่างต้องผ่านการอนุมัติก่อนรับงาน, เพดานค่าคอมที่ช่างค้างจากงานเงินสด, และหน้าการเงินของเจ้าของ
- ✅ แยกสิทธิ์เจ้าของและทีมงาน พร้อมบันทึกว่าใครทำอะไรเมื่อไหร่
- ✅ LINE Login ทั้งลูกค้าและช่าง (channel 2011772186) ทดสอบเข้าได้จริงแล้ว
- ✅ สคริปต์ติดตั้ง `deploy/install.sh` ซ้อมติดตั้งจริงด้วย docker compose ผ่านแล้ว: ติดตั้งจากศูนย์, รันซ้ำ, HTTPS, ทดสอบงานจริงครบวงจร, สำรองและกู้คืนข้อมูล
- ✅ ตรวจ DNS ก่อนติดตั้ง (`deploy/preflight.sh`) และตรวจสุขภาพระบบหลังติดตั้ง (`deploy/doctor.sh`)
- ✅ ข้อความและภาพหน้าจอสำหรับลงสโตร์: `docs/STORE_LISTING.md`, `docs/store/`
- ✅ นโยบายความเป็นส่วนตัว ข้อตกลงการใช้งาน และหน้าขอลบบัญชี (ฉบับร่าง)
- ✅ เซิร์ฟเวอร์จริง Hostinger VPS ติดตั้งด้วย `install.sh` แล้ว HTTPS ครบ 4 โดเมน สำรองข้อมูลทุกวันตี 3
- ✅ โดเมนจริง: `fixgothai24.tech` (ลูกค้า), `fixer.fixgothai24.tech` (ช่าง), `admin.fixgothai24.tech` (แอดมิน), `api.fixgothai24.tech` (API)
- ✅ ทดสอบอัตโนมัติครบวงจร `npm run test:http` รันทุก PR

## 1. ข้อมูลที่ install.sh ถาม (ใช้ตอนติดตั้งใหม่หรือย้ายเครื่อง)

`install.sh` จะถามตามลำดับนี้ เตรียมคำตอบไว้ก่อน ติดตั้งจะเสร็จในรอบเดียว

| คำถาม | ตัวอย่าง / หมายเหตุ |
|---|---|
| โดเมนหลัก | `fixgothai24.tech` |
| เบอร์พร้อมเพย์ที่รับเงิน | เบอร์ของ **บัญชีธนาคารที่แยกไว้ใช้กับ FixGo** (ดูข้อ 2) |
| ชื่อบัญชีพร้อมเพย์ | ให้ตรงกับชื่อที่แอปธนาคารแสดงตอนสแกน |
| ชื่อกิจการ, เบอร์ติดต่อ, อีเมล, ที่อยู่ | แสดงในนโยบายความเป็นส่วนตัวและปุ่มโทรบนเว็บ |
| SMS | เลือก 2 (ยังไม่ใช้ SMS) แล้วใส่เบอร์ทีมงาน |
| LINE Login Channel ID และ Channel secret | Channel ID `2011772186` secret ดูใน LINE Developers > Basic settings **ห้ามส่ง secret ในแชท** พิมพ์ลงเครื่องเซิร์ฟเวอร์เท่านั้น |
| เบอร์และรหัสผ่านแอดมิน | รหัสผ่าน 12 ตัวขึ้นไป บัญชีนี้เป็น **เจ้าของ** |

## 2. งานที่เหลือของเจ้าของ

- [ ] **ออก LINE Channel secret ใหม่** (LINE Developers > Basic settings > Issue) แล้วใส่ `LINE_LOGIN_CHANNEL_SECRET` ใน `deploy/.env.production` รัน `sudo bash deploy/install.sh` อีกครั้ง **ก่อน** กด Publish channel
- [ ] **กด Publish channel LINE Login** หลังเปลี่ยน secret แล้ว (ระหว่างเป็น Developing ใช้ได้เฉพาะบัญชี tester)
- [ ] **ใส่ `LEGAL_ADDRESS`** ใน `deploy/.env.production` แล้วรัน install.sh อีกครั้ง ตอนนี้หน้า privacy ยังขึ้น `[ที่อยู่บริษัท]`
- [ ] **ทดสอบบนมือถือจริง 1 รอบ** (มือถือ 2 เครื่อง หรือเครื่องเดียวกับคอมพิวเตอร์)
  1. เปิด `https://fixer.fixgothai24.tech` สมัครช่างด้วย LINE กรอกข้อมูลให้ครบ
  2. `https://admin.fixgothai24.tech` > ช่างรออนุมัติ > โทรเช็กเบอร์ > อนุมัติ
  3. ช่างเปิด "พร้อมรับงาน"
  4. เปิด `https://fixgothai24.tech` อีกเครื่อง เข้าด้วย LINE แล้วเรียกช่าง
  5. ช่างรับงาน เดินทาง ส่งราคา ลูกค้ายืนยัน ช่างปิดงาน
  6. ลูกค้าสแกน QR (โอนจริง 1 งานด้วยยอดน้อยได้ หรือกดแนบสลิปทดสอบ) แอดมินกดยืนยัน
  7. ดูหน้า "การเงิน" ว่าตัวเลขตรง
- [ ] **ให้นักกฎหมายตรวจ** นโยบายความเป็นส่วนตัวและข้อตกลงการใช้งาน (`https://api.fixgothai24.tech/api/legal/privacy`)
- [ ] **เปิดบัญชีธนาคารแยกสำหรับ FixGo** แล้วผูกพร้อมเพย์
  เงินพร้อมเพย์ที่ลูกค้าโอนมา 65% เป็นของช่าง ห้ามใช้ปนกับเงินส่วนตัว หน้าการเงินบอกยอดที่ต้องสำรองไว้
- [ ] **คัดลอกไฟล์สำรองออกนอกเครื่อง** อย่างน้อยสัปดาห์ละครั้ง (`deploy/backups/`) เช่นดาวน์โหลดเก็บในคอมพิวเตอร์หรือ Google Drive

## 3. เปิดรับช่างและลูกค้าจริง

- [ ] รับช่างชุดแรก 5–10 คนในพื้นที่เดียวกันก่อน (ส่งลิงก์ `https://fixer.fixgothai24.tech` ให้สมัครเอง)
- [ ] ถ้ามีคนช่วยดูแล เพิ่มบัญชี **ทีมงาน** ในหน้าแอดมิน (ทีมงานยืนยันเงินเข้าออกไม่ได้)
- [ ] ทุกสัปดาห์: `sudo bash deploy/doctor.sh` ดูว่ายังสำรองข้อมูลอยู่และดิสก์ไม่ใกล้เต็ม
- [ ] ทุกวัน: เปิดหน้าแอดมินดู "งานที่ไม่มีช่างรับ", "สลิปรอตรวจ", "ช่างรออนุมัติ", "คำขอเบิกเงิน"
- [ ] ทุกสัปดาห์: ดูหน้า "การเงิน" ดาวน์โหลด CSV เก็บไว้ส่งนักบัญชี

## 4. ทำภายหลังได้ (มีค่าใช้จ่ายหรือยังไม่จำเป็น)

| งาน | เมื่อไหร่ควรทำ | ค่าใช้จ่ายโดยประมาณ |
|---|---|---|
| Google Play (แอป Android) | เมื่อช่างอยากได้แจ้งเตือนงานเข้าแบบ push | ค่าสมัครนักพัฒนา 25 USD ครั้งเดียว |
| App Store (แอป iPhone) | เมื่อมีลูกค้า iPhone เยอะ ต้องใช้ Mac หรือบริการ build บนคลาวด์ | ค่าสมัครนักพัฒนา 99 USD ต่อปี |
| แจ้งเตือน push (Firebase) | พร้อมกับการขึ้น Google Play | ฟรี |
| SMS จริง (ThaiBulkSMS) | เมื่อมีลูกค้าที่ไม่ใช้ LINE จำนวนมาก | คิดตามจำนวนข้อความ |
| ที่เก็บรูป Cloudflare R2 | เมื่อดิสก์เซิร์ฟเวอร์ใกล้เต็ม | มีโควตาฟรี |

ภาพหน้าจอและข้อความสำหรับลงสโตร์อยู่ใน `docs/STORE_LISTING.md`

## 5. ก่อนลงสโตร์

- [ ] ตั้ง GitHub Variable `API_BASE_URL=https://api.fixgothai24.tech` (ตอนนี้ไฟล์ Android จาก CI ลงท้าย `-no-api-url`)
- [ ] สร้าง Android upload keystore แล้วใส่ใน GitHub Secrets (ตอนนี้ไฟล์ลงท้าย `-debug-signed` ส่ง Google Play ไม่ได้)
- [ ] เตรียมบัญชีทดสอบให้ทีมรีวิวตาม `docs/APP_REVIEW.md`

## ความปลอดภัย

- ✅ ufw เปิดแล้ว (อนุญาตแค่ 22/80/443) และ fail2ban เปิดแล้ว
- [ ] ใส่ SSH key ใน Termius ให้เข้าเครื่องได้ก่อน แล้วค่อยปิด `PasswordAuthentication no` ใน `/etc/ssh/sshd_config` (ลองเข้าด้วย key อีกหน้าต่างก่อนปิดหน้าเดิม)
- ห้ามส่งรหัสผ่าน, Channel secret, SSH key หรือไฟล์ `.env.production` ให้ใครทางแชท
- ห้ามแคปหน้าจอตอนที่รหัสลับแสดงอยู่ (รหัสผ่าน, secret, รหัส OTP ทดสอบ, เนื้อหา `.env.production`)
- ไฟล์ `deploy/.env.production` และไฟล์สำรองอ่านได้เฉพาะ root อยู่แล้ว อย่าเปลี่ยนสิทธิ์
- ทีมงานลาออก: หน้าแอดมิน > ทีมงาน > ปิดบัญชี มีผลทันที
