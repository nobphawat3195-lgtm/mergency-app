# 1. ภาพรวมโปรเจกต์และกลุ่มผู้ใช้

## ปัญหาที่แก้

คนขับรถทั่วไป (โดยเฉพาะคนไม่มีความรู้เรื่องรถ) เจอ 2 สถานการณ์บ่อย:

1. **รถเสียกะทันหัน** — สตาร์ทไม่ติด, แบตหมด, ยางแบน, กุญแจตกค้าง, ดับกลางทาง, อุบัติเหตุ — ต้องการช่างที่ไว้ใจได้มาถึงเร็ว ราคาโปร่งใส ไม่ถูกโก่งราคาเพราะความเดือดร้อน
2. **จะซื้อรถมือสอง** — ไม่มีความรู้เพียงพอจะเช็คสภาพรถเอง กลัวโดนหลอกขายรถชนหนัก/น้ำท่วม/ไมล์ปลอม ต้องการผู้เชี่ยวชาญไปตรวจให้ก่อนตัดสินใจซื้อ

## ภาพรวมตลาด

- แอปเรียกช่างรถในตลาดมักแยกเป็น 2 แอป: ฝั่งลูกค้าและฝั่งช่าง
- บริการหลักที่ตลาดคุ้นเคย: ปะยาง, จั๊มแบต/เปลี่ยนแบต, ลากรถ/สไลด์, กุญแจ, ไดนาโม, ตรวจอาการเบื้องต้น
- Booking แบบ wizard ทีละขั้น (บริการ → บริการย่อย → ประเภทรถ → ราคา) เหมาะกับผู้ใช้ที่ไม่มีความรู้ช่าง
- **บริการตรวจรถมือสองแบบมีรายงานละเอียดยังหาได้ยาก** ← นี่คือช่องว่างที่แอปเราจะเติมเต็ม

## จุดต่าง (Differentiation) ของเรา

| ด้าน | แอปทั่วไปในตลาด | แอปเรา |
|---|---|---|
| Emergency roadside | ✅ มี | ✅ มี (ปรับปรุง UX ให้เร็วขึ้น) |
| ตรวจรถมือสอง | ❌ ไม่มี | ✅ บริการหลักใหม่ พร้อม digital inspection report |
| รายงานผลตรวจ | - | Scorecard + รูปภาพ/วิดีโอ 360° + PDF ส่งในแอปทันที |
| ช่างผู้เชี่ยวชาญ | ช่างซ่อมทั่วไป | แยก badge "ผู้เชี่ยวชาญตรวจสภาพ" ต่างหาก |

## Personas

**1. คุณเอ (User ฝั่ง Emergency)**
- อายุ 25-45, ขับรถทำงาน/ใช้ในชีวิตประจำวัน
- ไม่มีความรู้ช่าง ตื่นตระหนกเมื่อรถเสีย ต้องการความเร็วและราคาที่ชัดเจนก่อนตัดสินใจเรียก
- ใช้งานตอนเครียด → UI ต้องเรียบง่าย ขั้นตอนน้อย ปุ่มใหญ่ ชัดเจน

**2. คุณบี (User ฝั่ง Inspection)**
- กำลังจะซื้อรถมือสองคันแรก/จากบุคคล ไม่ใช่จากศูนย์
- กลัวโดนหลอก อยากได้ "ความเห็นที่สอง" จากผู้เชี่ยวชาญ ก่อนโอนเงิน
- ใช้งานแบบวางแผนล่วงหน้า (นัดเวลา) ไม่เร่งด่วนเหมือนกลุ่มแรก

**3. ช่างทั่วไป (Fixer — Emergency)**
- รับงานตามพื้นที่ กดรับ-ปฏิเสธงาน อัปเดตสถานะ, ใช้แอปฝั่ง Fixer

**4. ผู้เชี่ยวชาญตรวจสภาพ (Inspector — Inspection)**
- ต้องผ่านการรับรอง/verify จากแอปก่อนรับงานตรวจรถได้ (ต่างจากช่างทั่วไป)
- ใช้ digital checklist + กล้องในแอปเพื่อบันทึกผลตรวจแบบมีโครงสร้าง

## หลักการออกแบบ UX

1. ลดจำนวนการตัดสินใจต่อหน้าจอ (ใช้ wizard ทีละขั้น เหมาะกับ user ที่ไม่มีความรู้ช่าง)
2. โชว์ราคาก่อนยืนยันเสมอ ไม่มีค่าใช้จ่ายซ่อนเร้น
3. แยกฟีเจอร์ตาม "อารมณ์การใช้งาน": Emergency = เร็ว/ตรงไปตรงมา, Inspection = ละเอียด/น่าเชื่อถือ
